# grants-gateway, smoke test

Generated by bead **bkt-ugw**. Confirms that the SQLite-backed
`SqliteGrantsStore` returns real grants pulled from grants.gov, NIH
RePORTER, NSF Awards, USAspending.gov, and IRS 990 / 990-PF filings
(via ProPublica Nonprofit Explorer).

## How to reproduce

```bash
cd grants-gateway
npm install
python3 scripts/ingest.py            # all sources, ~10–20 min
# or one at a time:
python3 scripts/ingest.py --source=grants_gov
python3 scripts/ingest.py --source=nih
python3 scripts/ingest.py --source=nsf
python3 scripts/ingest.py --source=usaspending
python3 scripts/ingest.py --source=foundations

GRANTS_STORE=sqlite npm run dev
# → [grants-gateway] store=sqlite (NNNN rows)
# → [grants-gateway] listening on :8789
```

The `GRANTS_STORE` env var picks the backing store, default is
`memory` (5 fixtures), set to `sqlite` to read `data/grants.db`. The
DB file is gitignored.

## Discovery

```bash
curl -s localhost:8789/.well-known/feed402.json | jq '{spec, chain, tiers: .tiers, chunks: .index.chunks, corpus_sha256: .index.corpus_sha256}'
```

## Tier 1, `/grants/raw`

Pick any id from the corpus (e.g. `nih-reporter:<appl_id>` or
`grants-gov:<opportunity_number>`):

```bash
curl -s -H 'x-payment: stub' \
  "localhost:8789/grants/raw?id=nih-reporter:10612345" | jq '.data.grant | {id,title,funder,amount_max_usd,canonical_url}'
```

## Tier 2, `/grants/query`

Topic + amount filter (uses SQLite FTS5 under the hood):

```bash
curl -s -H 'x-payment: stub' \
  "localhost:8789/grants/query?topic=marine+fisheries&min_amount=50000&limit=5" \
  | jq '.data.rows[] | {id, title, funder, amount_max_usd, deadline}'
```

Funder + deadline:

```bash
curl -s -H 'x-payment: stub' \
  "localhost:8789/grants/query?funder=NSF&deadline_before=2027-01-01&limit=10" \
  | jq '.data | {count, sample: .rows[0]}'
```

## Schema notes / known limitations

- **Per-grant 990-PF detail**: not yet ingested. Schedule B parsing
 from the IRS bulk XML feed is its own bead. For foundations we
 currently hold one row per filing year, with `amount_max_usd` set to
 total grants paid and the citation pointing at the ProPublica
 filing page. Eligibility text is therefore generic.
- **grants.gov detail enrichment**: the list call is fast, the detail
 call (`fetchOpportunity`) gives synopsis + eligibility + amounts.
 We cap detail enrichment at 1500 records per ingest run to keep
 pulls fast; non-enriched rows still have stable id, title, funder,
 deadline, canonical URL.
- **NIH RePORTER offset cap**: the public API caps offset at 14,999.
 We pull the most-recent 15k awards across the last 3 fiscal years.
- **NSF awards**: rpp=25 max per page; pagination via offset works
 but slower. Capped at 50k.
- **USAspending**: limited to grant award type codes (02-05) sorted
 by Award Amount desc, capped at 20k.

## Database file

- Path: `grants-gateway/data/grants.db`
- Format: SQLite + FTS5 virtual table `grants_fts`
- Pragmas: WAL, synchronous=NORMAL
- Upsert semantics: PRIMARY KEY = `id` (e.g. `grants-gov:HHS-2026-NIH-AG-001`);
 re-running ingest refreshes `last_seen_at` and any changed fields,
 no duplicates.
- Gitignored, never commit.

## Tier 3
`/grants/insight` with the real Anthropic synthesizer.

Default synth is `mock` (no API key needed). To exercise the real
`AnthropicSynthesizer`:

```bash
export ANTHROPIC_API_KEY=sk-ant-...
export INSIGHT_SYNTH=anthropic
# optional: pin a model. Default is claude-sonnet-4-5.
export ANTHROPIC_MODEL=claude-sonnet-4-5

GRANTS_STORE=sqlite npm run dev
# → [grants-gateway] insight_synth=anthropic (claude-sonnet-4-5)

curl -s -H 'x-payment: stub' \
  "localhost:8789/grants/insight?venture=bucket-foundation&topic=open-source%20citation%20infrastructure" \
  | jq '{summary: .data.summary, matches: .data.matches[0:3], provenance}'
```

The envelope carries an envelope-level `provenance` block (sibling of
feed402 §3.2 retrieval provenance, but tracking *synthesis* not retrieval):

```json
"provenance": {
  "model_id": "claude-sonnet-4-5",
  "candidates": [{"id": "grants-gov:HHS-2026-NIH-AG-001", "score": 0.333}, ...],
  "prompt_sha256": "9f3a...e7c1",
  "ts": "2026-05-04T16:01:23.456Z"
}
```

Budget guard: projected per-call cost exceeding `10 × $0.002 = $0.02` is
logged and downgraded to `MockSynthesizer` (the envelope then ships
without `provenance`). Output tokens are hard-capped at 600.
