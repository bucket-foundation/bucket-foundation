## Abstract

This study continues investigating the consonance-pattern emerging neural network model introduced in our previous publication, specifically to test if it will reproduce the results using 100-fold finer precision of 1/100th of a semitone (1 cent). The model is a simplistic feed-forward generic Hebbian-learning generic neural network trained with multiple-harmonic complex sounds from the full auditory sound spectrum of 10 octaves.
