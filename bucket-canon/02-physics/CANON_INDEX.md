# 02-physics — Canon Index (master)

Master index for the physics canon branch. Each sub-folder will maintain its own `CANON_INDEX.md`; this file is the single hop a researcher takes from the branch root.

Promotion rule lives in `README.md`. Adjudication history lives in `_intake/`.

## Sub-folders (proposed; ratified in pass-2)

| Sub-folder | Scope | Index |
|---|---|---|
| `classical-mechanics/` | Newton, Lagrange, Hamilton, Jacobi, Noether — laws of motion, action principles, symmetries and conservation | (pending pass-2) |
| `electromagnetism/` | Faraday's experimental researches, Maxwell's *Treatise*, Heaviside's vector form, Lorentz force law and electron theory | (pending pass-2) |
| `thermodynamics/` | Carnot cycle, Clausius's two laws and entropy, Helmholtz on conservation of energy, Planck's black-body law | (pending pass-2) |
| `statistical-mechanics/` | Boltzmann's H-theorem and statistical entropy, Gibbs's *Elementary Principles*, Einstein on Brownian motion, Onsager reciprocal relations | (pending pass-2) |
| `relativity/special/` | Einstein 1905 *Annalen* trio (photoelectric, Brownian, special relativity, E = mc²), Minkowski's spacetime formulation | (pending pass-2) |
| `relativity/general/` | Einstein 1915–1916 field equations, Hilbert's parallel variational derivation, Schwarzschild's exact solution | (pending pass-2) |
| `quantum-mechanics/` | Heisenberg matrix mechanics, Born-Heisenberg-Jordan, Schrödinger wave mechanics, Born probability interpretation, Dirac's relativistic equation and *Principles*, Pauli exclusion, Born-Oppenheimer separation, von Neumann axiomatization | (pending pass-2) |
| `quantum-field-theory/` | Tomonaga-Schwinger-Feynman-Dyson on renormalized QED, Yang-Mills non-abelian gauge theory, Higgs and Englert-Brout on mass generation | (pending pass-2) |
| `particle-physics/` | Glashow-Weinberg-Salam electroweak unification, Gross-Wilczek-Politzer asymptotic freedom; Particle Data Group reference lives in `reference/` | (pending pass-2) |
| `condensed-matter/` | Bardeen-Cooper-Schrieffer superconductivity, Anderson localization, Wilson renormalization group | (pending pass-2) |
| `reference/` | CODATA recommended values, BIPM SI brochure, PDG *Review of Particle Physics* | (pending pass-2) |
| `_landscape/` | Discipline-standard textbooks that do NOT promote to canon (Jackson, Sakurai, Griffiths, Peskin-Schroeder, Halliday-Resnick, Landau-Lifshitz *Course*, MTW *Gravitation*, Wald *General Relativity*, Weinberg *QFT*). Registry only, no folder explosion. | (pending pass-2) |
