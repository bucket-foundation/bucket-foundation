# 06-cosmology — Canon Index (master)

Master index for the cosmology canon branch. Each sub-folder will maintain
its own `CANON_INDEX.md`; this file is the single hop a researcher takes
from the branch root.

Promotion rule lives in `README.md`. Adjudication history lives in
`_intake/`.
