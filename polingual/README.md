# polingual

Language-focused frontend for the photon graph. Sister product of
bucket.foundation. Same substrate (photon index), different lens.

See `../POLINGUAL.md` and `../PHOTON-SPEC.md` for the canonical specs.

## Status

- Domain: polingual.com (purchased 2026-05-13)
- Photon substrate: shared with bucket-foundation
- Code: stub, building incrementally

## Quickstart

```bash
# Same repo, different workspace. Bucket photons are in:
ls ../_intake/photons/

# Run the dev server:
npm install
npm run dev
```
