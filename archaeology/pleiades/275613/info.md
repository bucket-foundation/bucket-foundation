## Description

An ancient body of water, mentioned by Scylax and Pliny the Elder (who terms it a "lacus"), bordering the Atlantic coast in what is now northwest Morocco. Some modern scholars believe it should be associated with the modern Oued Tahadart/Oued Khobs near El Khaoucha.
