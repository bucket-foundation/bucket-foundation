## Description

An island mentioned in various ancient sources with some drift or corruption in the representation of the name. It has long been identified by scholars with the island now known as Rathlin, which is located off the modern northern Irish coast, but Fitzpatrick-Matthews has recently argued for an identification with Jura in Scotland's Inner Hebrides.
