## Description

"In Alpe Maritima" is a name that appears on the Peutinger map. Talbert notes that this name seems to be isolated; it is placed in the water and may refer to an otherwise unique symbol on the shoreline that might be meant to indicate cliffs. There is some uncertainty about the interpretation of this place name.
