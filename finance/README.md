# Finance Atlas

Bucket Foundation initiative, bead `bkt-q5moa`. Sibling of `quantum/` and the health manual. Goal: index all of money and markets, from the history of money through every asset class to quant methods, then compile the sources into a notify-first investment and trading system.

## Read Order
1. `00-map/00-IDEAL-STATE-MAP.md`: the whole territory
2. `02-assets/2026-STATE.md`: what is happening now
3. `03-data-sources/DATA-SOURCES.md`: where backtest and live data comes from, free and paid
4. `07-system/SYSTEM.md`: the trading and alert system built from the atlas

## Folders
| Dir | Holds |
|-----|-------|
| `00-map/` | ideal-state map, coverage |
| `01-money-history/` | barter to stablecoins, long-run return datasets |
| `02-assets/` | one card per asset class, 2026 state |
| `03-data-sources/` | backtest and live data vendors, prices, licenses |
| `04-quant/` | time series, stochastic processes, MDPs, strategies, risk, overfitting |
| `05-education/` | routes to quant research, dev and trading; books, courses, frameworks |
| `06-youtube/` | transcript corpus of trading-system builds, index, synthesis |
| `07-system/` | system design, alerting, paper-trading plan |
| `09-strategies/` | 180 strategy cards with sources, decay and retail grades |
| `13-frontier/` | open problems and contested claims, both sides sourced |
| `14-papers/` | 1000 paper cards, the citation canon across 15 topics, with a citation-network summary |
| `16-macro/` | 85 macro cards: monetary theory, central banks, plumbing, fiscal, inflation, cycles, indicators, global dollar; daily brief dashboard spec |
| `sources/` | source registry |

## Principles
Every claim carries a source and a date. Backtests are graded for overfitting before they are trusted. The system alerts the founder first and trades only after paper results clear the bar in `07-system/`.
