# Library

Bead `bkt-q5moa.8`. 154 book cards in `books/` and 12 syllabus cards in `syllabi/`. Start with `READING-ORDER.md`.

Metadata comes from the Open Library search and edition APIs, fetched 2026-11-27. Contents come from the first Open Library edition record that carries a table of contents. Free copies are listed only when the author hosts the book or the edition is public domain on the Internet Archive; each link returned HTTP 200 or an archive search hit on the fetch date. Google Books hit its daily quota during the run, so no card cites it.
