💎 WHY FREQTRADE?
━━━━━━━━━━━━━━━━━━━━
Freqtrade is free, open-source (GPLv3), and self-hosted—your API keys never leave your machine. Unlike SaaS bots, you get full control over strategy logic, execution, and data. It ships with backtesting, Hyperopt, FreqAI (machine-learning strategies), dry-run/paper trading, a web dashboard (FreqUI), and Telegram control. It supports 20+ exchanges via CCXT, including Binance, Kraken, and others.

━━━━━━━━━━━━━━━━━━━━
⚠️ IMPORTANT SAFETY NOTE
━━━━━━━━━━━━━━━━━━━━
Trading bots do not guarantee profits. Freqtrade is powerful, but it is not a “set-and-forget money printer.” Always start in dry-run mode—dry-run does not require exchange API keys and simulates trades with a paper wallet. When you go live, use IP-restricted API keys and never enable withdrawal permissions.
