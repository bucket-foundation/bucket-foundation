## Architecture
Package `src/finoptions/`: `vanillaoptions.py`, `basic_american_options/`, `binomial_tree_options/`, `heston_nandi_options/` (with `hnGARCH.py`), `monte_carlo_options/` (innovations, paths, payoffs), `spread_options/` (3D tree, approximations). Python port of the R fOptions package with an object-oriented API and finite-difference greeks.

## Data Layer
Pricing inputs passed as scalars or arrays; nine notebooks for examples.
