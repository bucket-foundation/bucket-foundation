## Architecture
Training course. `notebooks/` holds modules 1.1 to 2.6 (distributions, covariance, OLS, PCA, Bayesian updating, moving averages, stationarity, ARMA, Kalman filter, ARIMA, GARCH, overfitting), `notebooks/solutions/` with about 100 small exercise scripts, `notebooks/custom/figures.py` and a `datasets_required.txt`.

## Data Layer
Downloaded crypto and equity price files, listed in `datasets_required.txt`. `my_secrets_template.py` holds API key placeholders.

## Event Loop
None. Notebook cells.

None.

Modules on confidence intervals, residual analysis and model instability. No risk system.
