# NOF0

https://github.com/wquguru/nof0. License none. Stars 2,755. Last push 2025-12-07. Go and TypeScript. Checked 2026-11-27.

## Architecture
Open arena for LLM traders: Go-Zero backend in `go/`, Next.js leaderboard in `web/`, MCP tools in `mcp/`, gitbook docs.

## Data Layer
Hyperliquid market data and account state.

## Event Loop
Scheduled agent cycles per model.

## Execution
Orders on Hyperliquid by each LLM agent.

## Risk
Per-agent leverage and position caps in config.

## Strategies Shipped
LLM models decide actions from market prompts.

## AI Components
Multiple LLMs compete with equal capital and a public leaderboard.

## Connectors
Hyperliquid.

## Fit
Reference for running and ranking several LLM trading agents side by side. No license.
