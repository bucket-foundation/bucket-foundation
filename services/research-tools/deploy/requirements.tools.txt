# research-tools-gateway — FAT/standard image deps.
# ===================================================
# This image vendors the 5 CPU-feasible subprocess tools (labbrain, proteinscout,
# stabilitydesigner, screenserver, patchseqml) IN ADDITION to the 9 self-contained
# REAL tools the lean image ships. The 2 genuinely GPU/heavy tools (trajmine real
# MD, cryotriage real cryo-EM) stay in their documented demo/synthetic mode — they
# need no extra deps here (demo path is numpy/scipy/matplotlib).
#
# CPU-only. torch is pulled CPU-only (see Dockerfile --index-url) for labbrain's
# sentence-transformers; no CUDA, no GPU. Sized for the Hetzner CPX42 (no GPU).

# --- the 9 lean-image tools + the 4 gap-research tools (unchanged deps) ---
# The gap-research cluster (ProtocolGPT, ToxinChannelFinder, CitationGraph) and
# QuantumBioRAG are pure stdlib (re/math/urllib) over the existing fastapi/
# pydantic + the tools_rag OpenAlex client — they add NO new dependencies.
#
# NEW (2026-06-21) — three more REAL clusters, all CPU, no GPU:
#   * imaging/mechanobiology (tools_imaging.py): CalciumTraceML, CellSegTrack,
#     AFM-CurveML, TractionForceML — scipy + scikit-image (already present for
#     cryotriage) + numpy. CellSegTrack uses Cellpose ONLY if installed; it is
#     NOT pinned here (heavy) — the classical Otsu+watershed path is the default.
#   * FigureMiner (tools_figure.py): text-layer caption + statistics mining —
#     stdlib re + an optional PDF text backend (PyMuPDF preferred, pypdf
#     fallback; both already present below for labbrain/screenserver). Raw-text
#     input needs NO PDF backend.
#   * genomics/sequence (tools_genomics.py): ChromatinAccess, AggregatePredict,
#     ChannelDwell — pure numpy + stdlib re. NO new dependencies.
# Net new hard dependency vs the prior fat image: PyMuPDF (for FigureMiner PDF
# input). scikit-image + scipy + numpy + pypdf are already pinned below.
