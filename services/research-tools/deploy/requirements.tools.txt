# research-tools-gateway, FAT/standard image deps.
# ===================================================
# This image vendors the 5 CPU-feasible subprocess tools (labbrain, proteinscout
# stabilitydesigner, screenserver, patchseqml) IN ADDITION to the 9 self-contained
# REAL tools the lean image ships. The 2 GPU/heavy tools (trajmine real
# MD, cryotriage real cryo-EM) stay in their documented demo/synthetic mode, they
# need no extra deps here.
#
# CPU-only. torch is pulled CPU-only for labbrain's
# sentence-transformers; no CUDA, no GPU. Sized for the Hetzner CPX42.

# --- the 9 lean-image tools + the 4 gap-research tools ---
# The gap-research cluster and
# QuantumBioRAG are pure stdlib over the existing fastapi/
# pydantic + the tools_rag OpenAlex client, they add NO new dependencies.
#
# NEW, three more REAL clusters, all CPU, no GPU
# * imaging/mechanobiology: CalciumTraceML, CellSegTrack
# AFM-CurveML, TractionForceML, scipy + scikit-image (already present for
# cryotriage) + numpy. CellSegTrack uses Cellpose ONLY if installed; it is
# NOT pinned here, the classical Otsu+watershed path is the default.
# * FigureMiner: text-layer caption + statistics mining
# stdlib re + an optional PDF text backend (PyMuPDF preferred, pypdf
# fallback; both already present below for labbrain/screenserver). Raw-text
# input needs NO PDF backend.
# * genomics/sequence: ChromatinAccess, AggregatePredict
# ChannelDwell, pure numpy + stdlib re. NO new dependencies.
# Net new hard dependency vs the prior fat image: PyMuPDF (for FigureMiner PDF
# input). scikit-image + scipy + numpy + pypdf are already pinned below.
#
# NEW, two ALL-FIELD horizontal metascience tools, CPU, NO GPU
# NO new dependencies:
# * FAIRCheck: FAIR
# rubric over Wilkinson 2016's 15 sub-principles + funder DMSP, pure stdlib
# . NO new dependencies.
# * RepliCheck: statcheck-style p-value recomputation + GRIM
# test + reporting flags, uses scipy.stats (already pinned `scipy>=1.13`
# below) for exact two-tailed distributions. NO new dependencies.
# These serve EVERY discipline.
#
# NEW, FIVE per-field NON-bio tools, CPU, NO GPU
# * CausalDesigner: DAG construction + Pearl back-door
# criterion + valid adjustment set via d-separation, uses networkx (the ONE
# new dependency below).
# * MaterialsFeaturizer: Magpie-style composition
# descriptors from a built-in element table, pure stdlib. NO new dep.
# * PowerPlan: statistical power & sample size, scipy.stats
# noncentral t/F + normal/Fisher-z. NO new dep.
# * GeoSummary: trend + seasonality +
# spatial extent, numpy + scipy.stats. NO new dep.
# * MLReproCard: ML reproducibility rubric + model card
# pure stdlib. NO new dep.
# Net new hard dependency: networkx.
#
# NEW, FIVE per-field CLASSICAL-algorithm tools, CPU, NO GPU
# NO new dependencies:
# * SeqAlign: Needleman-Wunsch + Smith-Waterman
# pairwise alignment with a baked BLOSUM62 matrix, pure stdlib.
# * StoichBalance: chemical-equation balancing via exact
# rational null-space of the element matrix + limiting reagent, pure stdlib
# .
# * UnitDimCheck: SI dimensional analysis / unit conversion /
# equation consistency over the 7 SI base dims, pure stdlib.
# * SurvivalFit: Kaplan-Meier + Greenwood + median +
# Mantel-Cox log-rank, numpy + scipy.stats.
# * TimeSeriesForecast: Holt-Winters triple exponential
# smoothing + additive decomposition + holdout backtest, numpy (scipy
# optional for the Nelder-Mead param refinement; both already pinned).
# Net new hard dependency: NONE.
