# research-tools-gateway — FAT/standard image deps.
# ===================================================
# This image vendors the 5 CPU-feasible subprocess tools (labbrain, proteinscout,
# stabilitydesigner, screenserver, patchseqml) IN ADDITION to the 9 self-contained
# REAL tools the lean image ships. The 2 genuinely GPU/heavy tools (trajmine real
# MD, cryotriage real cryo-EM) stay in their documented demo/synthetic mode — they
# need no extra deps here (demo path is numpy/scipy/matplotlib).
#
# CPU-only. torch is pulled CPU-only (see Dockerfile --index-url) for labbrain's
# sentence-transformers; no CUDA, no GPU. Sized for the Hetzner CPX42 (no GPU).

# --- the 9 lean-image tools + the 4 gap-research tools (unchanged deps) ---
# The gap-research cluster (ProtocolGPT, ToxinChannelFinder, CitationGraph) and
# QuantumBioRAG are pure stdlib (re/math/urllib) over the existing fastapi/
# pydantic + the tools_rag OpenAlex client — they add NO new dependencies.
#
# NEW (2026-06-21) — three more REAL clusters, all CPU, no GPU:
#   * imaging/mechanobiology (tools_imaging.py): CalciumTraceML, CellSegTrack,
#     AFM-CurveML, TractionForceML — scipy + scikit-image (already present for
#     cryotriage) + numpy. CellSegTrack uses Cellpose ONLY if installed; it is
#     NOT pinned here (heavy) — the classical Otsu+watershed path is the default.
#   * FigureMiner (tools_figure.py): text-layer caption + statistics mining —
#     stdlib re + an optional PDF text backend (PyMuPDF preferred, pypdf
#     fallback; both already present below for labbrain/screenserver). Raw-text
#     input needs NO PDF backend.
#   * genomics/sequence (tools_genomics.py): ChromatinAccess, AggregatePredict,
#     ChannelDwell — pure numpy + stdlib re. NO new dependencies.
# Net new hard dependency vs the prior fat image: PyMuPDF (for FigureMiner PDF
# input). scikit-image + scipy + numpy + pypdf are already pinned below.
#
# NEW (2026-06-22) — two ALL-FIELD horizontal metascience tools, CPU, NO GPU,
# NO new dependencies:
#   * FAIRCheck (tools_fair.py): FAIR (Findable/Accessible/Interoperable/Reusable)
#     rubric over Wilkinson 2016's 15 sub-principles + funder DMSP — pure stdlib
#     (json + re). NO new dependencies.
#   * RepliCheck (tools_repli.py): statcheck-style p-value recomputation + GRIM
#     test + reporting flags — uses scipy.stats (already pinned `scipy>=1.13`
#     below) for exact two-tailed distributions. NO new dependencies.
# These serve EVERY discipline (the 1.17M-researcher corpus), not one field.
#
# NEW (2026-06-22, later) — FIVE per-field NON-bio tools, CPU, NO GPU:
#   * CausalDesigner (tools_causal.py): DAG construction + Pearl back-door
#     criterion + valid adjustment set via d-separation — uses networkx (the ONE
#     new dependency below).
#   * MaterialsFeaturizer (tools_materials.py): Magpie-style composition
#     descriptors from a built-in element table — pure stdlib (re). NO new dep.
#   * PowerPlan (tools_power.py): statistical power & sample size — scipy.stats
#     noncentral t/F + normal/Fisher-z (already pinned scipy>=1.13). NO new dep.
#   * GeoSummary (tools_geo.py): trend (Mann-Kendall/Theil-Sen) + seasonality +
#     spatial extent — numpy + scipy.stats (already pinned). NO new dep.
#   * MLReproCard (tools_mlrepro.py): ML reproducibility rubric + model card —
#     pure stdlib (json + re). NO new dep.
# Net new hard dependency: networkx (CausalDesigner only).
#
# NEW (2026-06-24) — FIVE per-field CLASSICAL-algorithm tools, CPU, NO GPU,
# NO new dependencies:
#   * SeqAlign (tools_seqalign.py): Needleman-Wunsch (global) + Smith-Waterman
#     (local) pairwise alignment with a baked BLOSUM62 matrix — pure stdlib.
#   * StoichBalance (tools_stoich.py): chemical-equation balancing via exact
#     rational null-space of the element matrix + limiting reagent — pure stdlib
#     (fractions, math).
#   * UnitDimCheck (tools_units.py): SI dimensional analysis / unit conversion /
#     equation consistency over the 7 SI base dims — pure stdlib (fractions, re).
#   * SurvivalFit (tools_survival.py): Kaplan-Meier + Greenwood + median +
#     Mantel-Cox log-rank — numpy + scipy.stats (already pinned).
#   * TimeSeriesForecast (tools_forecast.py): Holt-Winters triple exponential
#     smoothing + additive decomposition + holdout backtest — numpy (scipy
#     optional for the Nelder-Mead param refinement; both already pinned).
# Net new hard dependency: NONE (numpy/scipy already present).
