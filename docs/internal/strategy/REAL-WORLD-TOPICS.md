# Real-World Applicability For Knowledge Topics

Bead bkt-xjsyw. Plan only: the founder said not to start yet. This is why Bucket is not ready to go live.

## Problem

Each science atom teaches a law or derivation and checks it with recall and a self-rating. A learner finishes a deck able to restate Ohm's law and unable to size a resistor.

## Standard Every Topic Meets

1. One applied task per atom: a number to compute, a choice to make, or a thing to predict in a real setting.
2. At least four question types per deck: pick, calculate, order the steps, spot the error, match the term.
3. Milestones a learner can show, in the style of the language milestones (bkt-l3lpa). For example: "wired a circuit that lights", "priced a loan", "read a nutrition label".
4. A placement test per branch.

## Pilot

Pick one branch with 40 to 60 atoms. Write the applied task for each, run it with five beta users, and measure task accuracy at day 7 against recall-only.

## Dependencies

- Experiment framework, bkt-go6ko, for the pilot measurement.
- The question-type engine work in bkt-5ayq0.
