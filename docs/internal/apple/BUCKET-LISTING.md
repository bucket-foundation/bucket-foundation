## Description

Bucket teaches the foundations of seven branches of science: mathematics, physics, chemistry, information and computation, biophysics, cosmology and mind, plus a deck on learning to learn.

LEARN
Each foundation comes with a summary, its equation, a lesson at three depths and the sources behind it.

PRACTICE
Test yourself on any deck. Rate each answer and move on.

LANGUAGES
Build a language system from one language you know and up to six you want. Each word returns in every language of the set, with shared roots side by side, placement in each language, and speaking practice.

ONE ACCOUNT
Sign in with an email code to sync your progress with bucket.foundation. Every screen works without an account.

Bucket is free and has no ads.

## App Review Notes

Sign-in is optional and uses a one-time email code sent to the address entered. Every screen except Account works signed out. Learn shows the science decks; Learn, Languages opens language systems. The microphone and speech recognition prompts appear on the first speaking exercise. Delete account is under Account once signed in.
