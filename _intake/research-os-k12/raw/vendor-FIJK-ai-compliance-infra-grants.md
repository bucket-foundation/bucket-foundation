### Computed per-student-per-month AI cost estimate

**Assumptions** (as specified in the brief):
- 200 constrained tool calls/month, ~500 input + 150 output tokens each (find/quote/check/organize calls, not free-form generation)
- 50 short generations/month, ~800 input + 300 output tokens each

**Token totals per student per month:**
- Constrained calls: 200 × 500 = 100,000 input; 200 × 150 = 30,000 output
- Short generations: 50 × 800 = 40,000 input; 50 × 300 = 15,000 output
- **Total: 140,000 input tokens (0.14M) + 45,000 output tokens (0.045M)**

**Cost = (0.14 × input $/M) + (0.045 × output $/M)**

| Option | Input $/M | Output $/M | Cost / student / month | Cost at 1,000 students | Cost at 10,000 students |
|---|---|---|---|---|---|
| **Frontier-cheap: OpenAI GPT-4o mini** | $0.15 | $0.60 | 0.14×0.15 + 0.045×0.60 = **$0.048** | $48/mo | $480/mo |
| **Frontier-cheap: OpenAI GPT-5 mini** | $0.25 | $2.00 | 0.14×0.25 + 0.045×2.00 = **$0.125** | $125/mo | $1,250/mo |
| **Frontier-cheap: Claude Haiku 4.5** | $1.00 | $5.00 | 0.14×1.00 + 0.045×5.00 = **$0.365** | $365/mo | $3,650/mo |
| **Open model via API: Fireworks (16-80B tier, ~Llama 3.1 70B)** | $0.90 | $0.90 | 0.185×0.90 = **$0.167** | $167/mo | $1,665/mo |
| **Open model via API: Together AI Llama 3.3 70B** | $1.04 | $1.04 | 0.185×1.04 = **$0.192** | $192/mo | $1,924/mo |

**Reading:** GPT-4o mini is roughly 4x cheaper than GPT-5 mini and 8x cheaper than Claude Haiku at this constrained-call profile, because output tokens dominate the bill and GPT-4o mini's output rate ($0.60/M) is far below the others. The 70B open-model options land between GPT-5 mini and Claude Haiku, offering no cost edge over GPT-4o mini at this small-call, low-output-volume profile; open-model self-hosting only starts to pay off at higher volume per student or once a fixed GEX-class server's monthly cost is spread across enough concurrent students. With prompt caching on repeated system/tool-schema context (typical for a constrained tool-call harness), a further 50-80% cut on the input-token share is realistic on both Anthropic and OpenAI, which would push all frontier options closer to $0.02-0.10/student/month.

Sources for this computation: pricing rows above; assumptions and token counts as directed by the task brief.

**General rule on fiscal sponsorship (not independently re-verified via a live source this session, but well-established nonprofit-sector practice):** the large majority of US foundations require an applicant to hold either its own established 501(c)(3) determination letter or an active fiscal sponsorship arrangement (where a sponsor's existing 501(c)(3) status legally receives and administers the grant on the applicant's behalf) before they will issue a grant. A merely-pending 501(c)(3) application, on its own, is not normally sufficient. Of the funders above, only the **Tools Competition** explicitly states an open posture toward early-stage/unincorporated applicants in its own language; none of the others explicitly discuss fiscal sponsorship as an accepted path in the content reached this session, that should be confirmed by direct outreach to each, or by securing a fiscal sponsor now so Bucket has a clean answer ready for every application in this table.

**Category K summary:** Tools Competition is the one funder in this set with a genuinely open, staged, non-relationship-gated application process and a grant size ($50k Catalyst tier) that fits Bucket's current stage, apply now given the 2027-cycle announcement is imminent (September 2026). CZI and Schmidt Sciences are strong thematic fits but gated behind solicited RFAs rather than open doors, worth monitoring rather than cold-applying. Walton explicitly does not accept unsolicited proposals. NSF EDU and IES are legitimate federal paths but require identifying a specific open solicitation and accepting a long review cycle. Mozilla and Sloan could not be verified this session and need direct follow-up.
