# ChEMBL

Source: https://www.ebi.ac.uk/chembl/
Fetched: 2026-05-01

Operator: EMBL-EBI (European Bioinformatics Institute), Hinxton, UK. Maintained team includes Barbara Zdrazil, Anna Gaulton, A. Patrícia Bento. Governance via the ELIXIR infrastructure network. Scope: manually curated database of bioactive molecules with drug-like properties; integrates chemical structure, bioactivity, and genomic data. License: CC-BY-SA 3.0 Unported. Access: web UI plus REST web services. Sister resources: ChEMBL-NTD (neglected tropical disease), UniChem (cross-references), SureChEMBL (patent-derived compounds).

Canon relevance: not canon (curated database, not primary text). Candidate x402 data source. Cross-link to `03-chemistry/reference/databases/`.
