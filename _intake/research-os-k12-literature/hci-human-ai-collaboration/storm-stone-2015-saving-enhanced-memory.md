# Saving-Enhanced Memory

Saving a list of items to an external store before studying a second list improves
memory for the second, new list, while weakening memory for the saved list itself, a
split benefit and cost from the same offloading act.

## Key Claims

- Saving a first list before studying a second improved recall of the second list.
- The saved list itself was recalled worse than a list learned with no save option.
- The benefit persisted even when participants knew the saved file would be
  unavailable at test.

## Research Questions It Leaves Open

- Whether the same split holds when the save action is an AI answer rather than a
  person's own file save.
- Whether the size of the benefit tracks how effortful the save action is.

## How It Bears on Research OS

Names the trade Research OS's Quote tool is built to capture: saving an evidence span
rather than the claim itself should free resources for claim-building while weakening
memory for the saved span, a cost worth logging alongside the three-arm testbed in
`RESEARCH-QUESTIONS.md` Q8.
