# Revisiting the effects of project-based learning on students' academic achievement

A meta-analysis of project-based learning's effect on student academic achievement,
quantifying a pooled effect size and testing moderators of that effect.

## Key Claims

- Pooling across reviewed studies, project-based learning produced a positive effect on
  student academic achievement relative to comparison instruction.
- The meta-analysis tested moderators, finding the effect varies with implementation
  features rather than holding as one fixed quantity.
- The paper revisits and refines an earlier PBL achievement synthesis with a
  moderator-focused reanalysis.

## Research Questions It Leaves Open

- Which significant moderators map onto features Research OS's own design already varies
  (subject branch, session count) versus features held fixed by construction.
- Whether the pooled effect size sits closer to, or further from, `PREREGISTRATION-DRAFT.md`'s
  assumed d = 0.4 planning figure than the single Bastani and colleagues (2025) contrast
  currently cited.

## How It Bears on Research OS

Supplies an additional, moderator-tested effect-size anchor for `PREREGISTRATION-DRAFT.md`'s
Sampling Plan, whose current d = 0.4 to 0.5 assumption traces only to an unsourced heuristic
and one percentage-only contrast. Because this meta-analysis pools PBL-versus-comparison
achievement studies directly, it is a closer-fit external benchmark for the pedagogical family
Research OS's Production work sits inside, bearing on `PLAN-REVISION-2.md` section 2d's power
table.
